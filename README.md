## 关于课程及编程语言
计算概论B 大部分都是使用**Python**进行编程，关于**C++**的资料和内容很少（至少 Yan 的班是这样的）。这里相当于提供了一部分POJ的C++题解。
因此对于想用 C++ 在程序内存占用和耗时上薄纱 Python 的同学来说，除了老师提供的课程资料还更应关注两种语言之间的转换，善用AI和网络进行相关算法的学习。
