## 关于课程及编程语言
计算概论B 大部分都是使用 **Python** 进行编程，关于 **C++** 的资料和内容很少（至少 Yan 班是这样的）。这里相当于提供了一部分POJ的C++题解。
因此对于想用 C++ 在程序内存占用和耗时上薄纱 Python 的同学来说，除了老师提供的课程资料还更应关注两种语言之间的转换，善用AI和网络进行相关算法的学习。

## 关于练习
### 时间分配
Yan 班的同学都非常卷😋，大家花在计概的时间都很多，但我其实并没有放这么多精力在计概上，一方面我之前有打比赛的基础（虽然连普及组都打不过），对基本的语法已经有了了解，另一方面我是元培生科方向的，
其他的专业课也很占时间。所以要根据自己的情况来分配学习计概的时间，不要被别人打乱了自己的节奏。

这样说来好像像国庆假这种长假我都没怎么做题😅。

### 题目选择
练习当然是越多越好啦XD。

优先级最高的肯定是上课**讲义中的题目**和 **Assignment** 的题目，如果这些全都做完并且理解了算法内容的话其实 AK 就不是很难了。

其次就是**每日选做**。其实我每日选做也没有全部做完（做到后面开始摆烂了），但是上面的题目确实是极为优质的复习题和拓展题。整体难度其实也还可以，还有可能出现考试原题。

### Mock Exam
难蚌的是 Mock Exam 我就只去过一次，还是开学第一次。

虽然我没怎么去过，但是每次考试的题目我都会找一个完整的时间段限时做一遍，然后就发现自己一道都不会做（

Mock Exam 的题目要比平时做的练习题都要难，所以要做好心理准备。把它当成巩固和拓展知识的机会，即使模考 AC0 期末也是有可能 AK 的。
